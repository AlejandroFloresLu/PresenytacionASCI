# Presentación – Sistema de Gestión Integral UZDI (SNAI · PUCE)

Presentación web de la propuesta técnica de refactorización y del modelo de datos DDL PostgreSQL v8.

- `index.html` – Inicio y esquemas
- `modelo.html` – Modelo de datos v8
- `cambios.html` – 12 cambios propuestos
- `matriz.html` – Matriz de prioridad y conclusión
